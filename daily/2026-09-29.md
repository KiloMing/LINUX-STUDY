## 关键概念

- TransformStamped 包含时间戳、父坐标系 header.frame_id、子坐标系 child_frame_id，以及 translation / rotation。变换描述子坐标系在父坐标系中的位姿，可将子坐标系坐标转换到父坐标系。
- translation 为 x/y/z 平移；rotation 为 x/y/z/w 四元数，不是直接填欧拉角。Quaternion::setRPY(roll,pitch,yaw) 使用弧度，角度乘 π/180；tf2::toMsg 将 tf2 四元数转换成 geometry_msgs 消息。
- StaticTransformBroadcaster 发布固定关系 map → target_point 到 /tf_static；sendTransform 一次后保持节点存活，供之后加入的 listener 获取。已有 listener 的静态缓存与新 listener 能否收到数据是不同问题。
- TransformBroadcaster 发布 map → base_link 到 /tf，timer 每 10ms 更新时间戳并调用 sendTransform。当前值固定，所以使用动态发布机制并不代表数值正在移动；timer 只是触发方式之一。
- TransformListener 订阅 /tf 和 /tf_static，将变换存入 Buffer；Buffer 维护坐标关系与时间信息。
- lookupTransform("base_link", "target_point", tf2::TimePointZero) 查询 target_point 在 base_link 中的位姿，即 source → target 的坐标转换。零时间表示最新可用变换，链中动态边需满足共同时间；不等于强制查询此刻。
- 两个子坐标系共同连接 map 即可查询相对关系，无需另行发布 base_link → target_point；未收到数据时捕获 tf2::TransformException。

## 今日错误与解决办法

| 错误/现象 | 原因与处理 |
|---|---|
| tf-transformations 包名拼写错误 | 安装名按 ros-发行版-tf-transformations 核对（本机 Jazzy）；Python 导入名为 tf_transformations。当前 C++ 示例依赖 tf2 等，不需要为此新增 Python 依赖；本次未重新安装软件 |
| package.xml / CMake 重复 tf2_geometry_msgs | 每层各保留一次必要声明；本次实查均无重复。package.xml 描述包依赖，find_package 查找配置，ament_target_dependencies 绑定目标，三者不是互相替代 |
| 在 workspace/src 执行 colcon build | 默认在当前目录生成 build/install/log；回到 workspace 根构建。实查目前 tf_test/src 下已无这些目录，根目录仍保留正常产物；仓库现有忽略规则覆盖任意深度，不复制生成物 |
| 动态 TF 忘记 sendTransform | 填好消息不会自动发布，必须调用 broadcaster 的 sendTransform；实际源码已补齐，本次重跑成功 |
| 静态节点退出后新 listener 查不到 frame | 静态变换并非永久存盘；保持发布节点 spin，再启动查询者。不能理解成所有已有 Buffer 会立即清空 |
| tf2_echo 初期 frame does not exist | 发现及接收尚未完成时可短暂出现；本次也先警告后正常输出。持续失败需查发布进程、sendTransform、frame 拼写、环境与域配置 |
| CMake 依赖或 install 配置不全 | 两个 executable 均绑定 rclcpp/tf2/tf2_ros/tf2_geometry_msgs/geometry_msgs，并安装到 lib/${PROJECT_NAME}；本次构建成功 |
| tf_listen.cpp 尚未写完 | 实际停在 shared_ptr 声明，缺初始化、timer、查询与 main；按原内容归档为 drafts/tf_listen.cpp.incomplete，不加入 CMake，不宣称 5.3.3 已完成 |
