### Turtle Patrol：本次实际源码核验

接口 `turtle_patrol_interface/srv/SetTarget.srv`：

```text
float64 target_x
float64 target_y
---
bool accepted
string message
```

功能包 `src/controller.cpp`：

- `TurtleController : rclcpp::Node`，节点名 `turtle_controller`；相对 Service `set_target`，lambda 转发成员回调，句柄保存为 Service SharedPtr。
- main 已具备 `init → std::make_shared<TurtleController>() → spin → shutdown`。
- 成员初始值为 `target_x_{1.0}`、`target_y_{1.0}`、`has_target_{false}`。
- 合法请求范围当前为 `0 <= x,y <= 12`；保存坐标，执行 `has_target_=true`，返回 accepted=true / target accepted。此范围只是当前实现，尚未证明所有被接受坐标在 turtlesim 内可达，需统一项目边界。

- 正确包含 `turtlesim/msg/pose.hpp`；订阅相对 `turtle1/pose`，队列深度 10，回调打印 x/y/theta。
- CMake 已 find_package rclcpp、turtle_patrol_interface、turtlesim，并将三项绑定到 controller；安装到 lib/${PROJECT_NAME}。
- 功能包 package.xml 已有 `<depend>turtle_patrol_interface</depend>`，**仍缺 rclcpp 与 turtlesim 直接依赖**。本次只整理记录，未修改学习工程。
