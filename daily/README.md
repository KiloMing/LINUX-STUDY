# 每日学习记录

## 用途

保存每天真正发生的学习、测试、错误和实验。长期路线放在 `ROADMAP.md`，精确当前状态放在 `CURRENT.md`，这里不重复抄写整套课程。

## 前置

开始记录前先执行 `CURRENT.md` 的“下一次测试”。

## 当前证据

旧记录仍保留在 `DAY1/`–`DAY6/`。从新结构启用后，使用 `YYYY-MM-DD.md` 命名。

## 完成证据

一份有效记录至少写清：闭卷结果、独立完成的代码/实验、暴露的问题、下一次测试和参考依据。

## 新内容位置

复制 [TEMPLATE.md](TEMPLATE.md) 为日期文件；相关源码放进对应主题目录或项目目录。
