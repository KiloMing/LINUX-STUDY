## Costmap 与规划、控制职责

学习 Costmap2D 的 worldToMap()/mapToWorld()、resolution、origin。世界坐标单位为米，A* 使用栅格坐标；origin=(0,0)、resolution=0.05m 时，世界坐标 (1.5,2.0) 对应栅格 (30,40)，转换需检查越界。

索引转换：`index = y * width + x`、`x = index % width`、`y = index / width`。栅格中心的世界坐标为 `wx = origin_x + (mx + 0.5) * resolution`、`wy = origin_y + (my + 0.5) * resolution`。

GlobalPlanner/A* 决定路线，nav_msgs::msg::Path 保存参考路径，不直接控制电机；MPPI/Controller 根据 Path、机器人状态及局部 Costmap 生成速度指令，交给底盘控制链路。动态障碍可能涉及全局重规划与局部避障，两者职责不同。

## createPlan() 设计与代码审查

设计链路：`Costmap2D → worldToMap → blocked 快照 → astarSearch → 路径索引 → 世界坐标 → Path → MPPI`。锁内复制障碍、尺寸、origin 和 resolution，释放锁后执行搜索和构造 Path，避免长时间阻塞地图更新，并保证坐标转换使用与快照一致的参数。

| 审查问题 | 修正方向 |
|---|---|
| 残留 throw "not implemented" | 移除占位异常，否则后续代码不可达 |
| 取消条件误写为重复 frame_id 检查 | 正确调用 cancel_checker，区分坐标系与取消检查 |
| blocked 未 resize 即下标写入 | 按地图格数分配空间，避免越界和未定义行为 |
| origin 未赋值 | 与障碍快照一起从 Costmap 获取 origin_x/origin_y |
| A* 和 Path 仍在 Costmap 锁作用域 | 缩小锁作用域，只在复制快照时持锁 |
| 缺 StartOccupied | 与 GoalOccupied 分别检查起终点占据 |
| 使用 atan2/sin/cos | 建议显式包含 `<cmath>` |

以上已给出教学修正方案，尚未核验实际文件全部修复。Path 转换还讨论了相邻点 yaw、平面四元数和目标朝向。A* 搜索内部取消响应、完整 footprint 碰撞安全、平滑及精确起终点连接仍待验证。

## 运行错误与未定位事项

```text
Trying to publish feedback when the current goal handle is not active
Action callback is still running and missed deadline to stop
Checking for cancel but current goal is not available
Velocity command timed out. Braking.
```

前三项涉及 waypoint_follower / ActionServer 的 Goal 状态、取消和停止过程；最后一项是 diff_drive_controller 的速度命令超时制动。尚未定位首次触发是在启动、导航中、任务取消还是 Ctrl+C/生命周期停用阶段。不能直接归因于 A*，也不能仅凭同时出现就断定底盘超时由 Waypoint Follower 导致。
