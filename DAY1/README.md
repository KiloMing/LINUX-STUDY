# 一、Linux环境认识

## Mac是否可以作为Linux使用？

Mac不能完全替代Linux，但是可以作为Linux开发环境。

原因：

-   macOS和Linux都属于Unix-like系统
-   两者拥有大量相同命令
-   都支持ssh、vim、gcc/g++、git

对于嵌入式开发、C/C++开发、Git管理和Linux命令学习，Mac完全可以使用。

# 二、Linux文件权限

查看文件权限：

``` bash
ls -l
```

示例：

``` text
-rwxr-xr-- 1 kilo staff 1024 main.c
```

权限：

-   r：read，读取
-   w：write，写入
-   x：execute，执行

Linux权限分为：

-   User：文件拥有者
-   Group：所属用户组
-   Other：其他用户

# 三、Linux用户和用户组

查看当前用户：

``` bash
whoami
```

查看用户：

``` bash
cat /etc/passwd
```

用户信息格式：

``` text
用户名:x:UID:GID:描述:家目录:shell
```

统计用户数量：

``` bash
cat /etc/passwd | wc -l
```

查看用户组：

``` bash
cat /etc/group
```

查看当前用户所属组：

``` bash
groups
```

或者：

``` bash
id
```

# 四、chown文件权限管理

查看文件：

``` bash
ls -l
```

修改文件拥有者：

``` bash
sudo chown 用户 文件
```

例如：

``` bash
sudo chown root main.c
```

修改用户和组：

``` bash
sudo chown 用户:组 文件
```

例如：

``` bash
sudo chown kilo:staff main.c
```

# 五、Linux文件操作

创建文件：

``` bash
touch main.c
```

创建目录：

``` bash
mkdir test
```

复制文件：

``` bash
cp old.txt new.txt
```

移动或重命名：

``` bash
mv 原文件 新文件
```

例如：

``` bash
mv test.cpp main.cpp
```

# 六、输入输出重定向

覆盖写入：

``` bash
echo hello > test.txt
```

特点：

-   覆盖原文件内容

追加写入：

``` bash
echo world >> test.txt
```

特点：

-   保留原内容
-   在末尾追加

# 七、grep标准输入

执行：

``` bash

```

输入：

``` text

```

结束输入：


# 八、vim基础操作

vim三种模式：

## 普通模式

进入：

``` text
Esc
```

功能：

-   移动
-   删除
-   复制

## 插入模式

进入：

``` text
i
```

功能：

-   输入文字

## 命令模式

进入：

``` text
:
```

常用：

保存：

``` vim
:w
```

退出：

``` vim
:q
```

保存退出：

``` vim
:wq
```

强制退出：

``` vim
:q!
```
