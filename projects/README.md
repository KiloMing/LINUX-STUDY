# 综合项目

## 用途

用真实项目把多个知识点连成系统，作为 L4–L5 掌握度的主要证据。

## 前置

每个项目先列出所依赖阶段；缺少关键前置时先完成最小回补。

## 当前证据

现有 DAY2 多文件构建练习和 DAY4 Mini Shell 属于历史小练习，仍保留原路径；这里尚无新的综合项目。

## 完成证据

每个项目包含目标、接口、环境、运行方法、测试、失败模式、实验结果和复盘，能够由他人在相同环境下复现。

## 建议里程碑

1. Linux 并发任务处理器。
2. TCP/UDP 机器人遥测模拟器。
3. CMake 多模块 C++ 工程。
4. ROS 2 传感器到控制的数据流。
5. 仿真差速机器人与 odometry。
6. 真实底盘、建图与导航系统。

具体项目只在前置满足时启动，不为填目录而创建空壳。
